# Security Policy

## Supported Versions

Warren is pre-1.0: only the **latest release** receives security fixes.

## Reporting a Vulnerability

Please do **not** open a public issue for security vulnerabilities.

Report them through either channel:

- GitHub private vulnerability reporting: <https://github.com/Gradient-DS/warren/security/advisories/new>
- Email: **lex@gradient-ds.com**

Please include a description of the issue, steps to reproduce, the affected version(s), and any known impact.

You can expect an acknowledgement within 5 business days. We ask that you give us a reasonable window to investigate and ship a fix before any public disclosure.
